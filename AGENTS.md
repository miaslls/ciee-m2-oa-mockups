# Regras do projeto

- Este repositório contém mockups visuais para seis Objetos de Aprendizagem (OAs) do Módulo 2 do CIEE. Cada OA deve ser implementado em uma tarefa separada.
- Os componentes, tokens e convenções de layout compartilhados são a referência. Não redesenhe o sistema visual para cada OA. Amplie componentes compartilhados somente quando a reutilização for realista.
- Trabalhe apenas no OA solicitado e nos componentes compartilhados realmente necessários. Não refatore OAs não relacionados.
- Não invente conteúdo educacional ausente da especificação. A redação e a lógica de interação fornecidas nos próximos prompts são autoritativas.
- Este é um projeto de mockups visuais, não um curso SCORM de produção. Não adicione backend, banco de dados, autenticação, analytics ou persistência sem pedido explícito. Evite dependências desnecessárias.
- Preserve os fundamentos de acessibilidade: HTML semântico, foco visível, contraste, controles corretos e preferência por movimento reduzido.
- O azul normativo do CIEE para material digital é `#024089`. Inter é a fonte de títulos e interface; Roboto é a fonte de textos longos. Não use gradientes nem recrie ou redesenhe o logo CIEE.
- A viewport principal de revisão é 1440×900; mantenha o layout utilizável em larguras menores.
- Permaneça na branch `main`, salvo instrução explícita. Não crie branches automaticamente.
- Antes de cada commit, rode `npm run build` e corrija erros. Não faça commit de experimentos incompletos.
- Cada tarefa de OA termina em um único feature commit limpo, depois de revisão, correções e build. Faça push após esse commit.
